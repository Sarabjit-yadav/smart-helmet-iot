# Hardware Connections

Functional connections:
- Reed switch → digital input
- IR/proximity sensor → digital input
- MPU6050 → I2C
- MAX30102 → I2C
- DS18B20 → digital temperature input
- INA219 → I2C
- Buzzer → digital output
- LED → digital output

The exact GPIO numbers, power rails and I2C addresses must be taken from the verified final circuit. Do not rely on guessed pin assignments.
